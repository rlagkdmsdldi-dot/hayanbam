사용법
예약이 들어오면
  1. 해당 날짜의 수업 타임 칸을 누릅니다.
  2. ＋로 예약 인원을 올리고 저장.
  3. 홈페이지 문의 달력의 잔여석이 바로 바뀝니다.
  4. 정원이 차면 자동으로 마감됩니다.

취소되면 −로 줄이고 저장하면 다시 열립니다.

칸 보는 법

2/6 = 예약 2명 / 정원 6명
흰색 예약 없음 · 베이지 예약 있음
검정 마감 · 빗금 휴강 · ✎ 메모

쉬는 날 · 특별한 날

타임을 눌러 휴강을 켜면 홈페이지에서 선택할 수 없습니다. 그날만 정원을 바꾸거나, 예약자 이름을 메모로 남길 수 있습니다(손님에게 안 보임).

사용법
문의가 들어오면
  1. 홈페이지 문의 폼으로 들어온 내용이 여기에 쌓입니다. 새 문의는 탭에 숫자로 표시됩니다.
  2. 연락한 뒤 상태를 확인함 → 예약 확정 → 완료로 바꿔 두세요.
  3. 예약이 확정되면 예약 캘린더에서 인원을 ＋1 해야 자리가 잡힙니다.

삭제는 삭제를 두 번 눌러야 됩니다.

사용법
사진 올리기
  1. 바꾸고 싶은 자리의 사진 선택을 누릅니다.
  2. 휴대폰은 사진 보관함이나 카메라, PC는 폴더에서 사진을 고릅니다.
  3. 올리면 홈페이지에 바로 반영됩니다.

사진은 자동으로 알맞은 크기로 줄여서 올라갑니다. 여러 장을 한 번에 고를 수도 있어요(작업 기록).

기본 정원

모든 타임에 적용되는 정원입니다. 특정 날만 다르게 하려면 캘린더에서 그 타임을 눌러 바꾸세요.

비밀번호

바꾸면 다른 기기의 로그인은 모두 풀립니다. 로그인은 7일 동안 유지됩니다.

갤럭시: 메뉴(⋮) → 홈 화면에 추가

기본 정원

모든 수업 타임의 기본 정원입니다. 타임별로 다르게 하려면 캘린더에서 해당 타임을 눌러 바꿔 주세요.

비밀번호 변경

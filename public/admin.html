사용법
예약이 들어오면
  1. 해당 날짜의 수업 타임 칸을 누릅니다.
  2. ＋로 예약 인원을 올리고 저장.
  3. 홈페이지 문의 달력의 잔여석이 바로 바뀝니다.
  4. 정원이 차면 자동으로 마감됩니다.

취소되면 −로 줄이고 저장하면 다시 열립니다.

칸 보는 법

2/6 = 예약 2명 / 정원 6명
흰색 예약 없음 · 베이지 예약 있음
검정 마감 · 빗금 휴강 · ✎ 메모

쉬는 날 · 특별한 날

타임을 눌러 휴강을 켜면 홈페이지에서 선택할 수 없습니다. 그날만 정원을 바꾸거나, 예약자 이름을 메모로 남길 수 있습니다(손님에게 안 보임).

예약 없음예약 있음마감휴강✎ 메모
사용법
정규반 등록 (주 1~4회)
  1. + 수강 등록을 누르고 이름을 입력합니다.
  2. 조소반 또는 유화반을 고르고 주 몇 회인지 선택합니다.
  3. 요일과 시간, 시작일을 고르면 4주치 일정이 자동으로 계산됩니다.
  4. 등록을 누르면 예약 캘린더에 이름이 들어갑니다.

휴강으로 막힌 날은 자동으로 건너뛰고 다음 수업으로 채워집니다.

원데이 클래스

날짜와 시간만 고르면 그날 한 번 등록됩니다.

쉬는 날 · 연장

수강생 카드에서 쉬는 날짜를 누르면 그 회차가 맨 뒤로 한 회 미뤄집니다. 공방 전체 휴강은 캘린더에서 그 칸을 휴강으로 바꾸면 정규 수강생이 자동으로 미뤄집니다. 4주가 끝나면 다음 4주 연장.

수정 · 결제

수정에서 이름·연락처·결제 정보를 바꾸고, 요일·시간도 바꿀 수 있습니다(지난 수업은 그대로). 카드 아래 미결제/결제 완료를 눌러 바로 바꿀 수 있습니다.

사용법
문의가 들어오면
  1. 홈페이지 문의 폼으로 들어온 내용이 여기에 쌓입니다. 새 문의는 탭에 숫자로 표시됩니다.
  2. 연락한 뒤 상태를 확인함 → 예약 확정 → 완료로 바꿔 두세요.
  3. 예약이 확정되면 예약 캘린더에서 인원을 ＋1 해야 자리가 잡힙니다.

삭제는 삭제를 두 번 눌러야 됩니다.

사용법
사진 올리기
  1. 바꾸고 싶은 자리의 사진 선택을 누릅니다.
  2. 휴대폰은 사진 보관함이나 카메라, PC는 폴더에서 사진을 고릅니다.
  3. 올리면 홈페이지에 바로 반영됩니다.

사진은 자동으로 알맞은 크기로 줄여서 올라갑니다. 여러 장을 한 번에 고를 수도 있어요(작업 기록).
